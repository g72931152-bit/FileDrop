FileDrop / UI State Gallery / v1 (0.15)

Logo + system-state variants

Blue is the normal identity. Yellow is a warning that the user can act on. Red is reserved for a critical state where the file or share cannot be recovered. The classic logo is deliberately pixelated and flat for the 2000s easter egg.

info

Information / checking

Checking the share, calculating a hash or waiting for a result.

Example: Loading share…
success

Success / released

The transfer completed and the share is ready.

Example: File uploaded successfully.
warning

Warning / send blocked

Potentially risky content or a configured share limit needs attention.

Example: Unable to send this file — review the rules.
critical

Critical / missing file

The file cannot be located or the share is no longer recoverable.

Example: File could not be found.
locked

Protected / password required

The share exists but the recipient must unlock it first.

Example: Password required to continue.
offline

Offline / unavailable user

The profile is unavailable or the person is not currently reachable.

Example: User is currently offline.
Recommended error-page composition
Unable to send this fileThe selected share is no longer available. Review its expiration or download limit, then create a new share.
File could not be foundThe share exists in metadata, but the temporary storage no longer contains the file.
